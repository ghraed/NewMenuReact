# Known Issues

Last reviewed: 2026-08-02

## Open launch blockers

### Tracked private SSH credentials require rotation and history remediation

- Status: open blocker.
- Evidence: the mobile repository contained tracked OpenSSH and PuTTY private-key files. They have been removed from the working tree and added to `.gitignore`.
- Required action: revoke/rotate the associated SSH credential, remove the key material from every accessible Git remote/history, and document the rotation. Deleting the current files does not invalidate a copied credential or remove historical exposure.

### Frontend dependency audit has two high findings

- Status: open blocker.
- Evidence: `npm audit` reports two high-severity findings for `react-router` and `react-router-dom` (React Server Components mode CSRF advisory). The installed `7.18.2` release remains in npm's affected range; npm's proposed `7.11.0` downgrade is not an acceptable security fix.
- Scope note: this frontend is a Vite client SPA and the review found no RSC/SSR entry point. That reduces apparent applicability but is not a replacement for an upstream patched release or a documented compensating control accepted by security review.

### Android release signing is not configured

- Status: open blocker for mobile distribution.
- Evidence: `./gradlew verifyReleaseSigning --no-daemon` fails intentionally with `Production signing is not configured` when no production keystore or `ANDROID_RELEASE_*` variables are supplied.
- Required action: provision the production signing key through the release secret store and rerun the guard. Do not distribute an unsigned or debug-signed build.

## Open risks

### Production frontend bundle is large

- Severity: high performance risk.
- Evidence: production build emits a Vite warning. The main bundle is 2,319.74 kB minified (641.63 kB gzip); the Three.js chunk is 759.64 kB minified (208.33 kB gzip).
- Required action: profile initial-route imports and split non-critical admin, 3D, and print functionality before broad launch. Validate on representative restaurant network conditions.

### Coverage and runtime matrix are incomplete

- Severity: medium.
- No backend or frontend coverage report was generated by the configured commands.
- Playwright runs only Desktop Chrome/Chromium. Firefox, WebKit, mobile-browser viewport, physical Android/iOS device, push, realtime, printer/PDF device behavior, and live payment-provider behavior remain untested.
- No PHPStan or Psalm configuration was found; backend semantic static analysis is therefore limited to Pint and PHP syntax checks.

### Critical transactional performance is unmeasured

- Severity: medium.
- Local static-preview ApacheBench passed, but no load test measured order creation, retries, inventory locks, reservation contention, queue depth, or database latency.
